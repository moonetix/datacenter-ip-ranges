What it is for

Three checks a rewards app, site, game or community can run with these lists.

  • Screen sign-ups

    Check the address at sign-up and skip the welcome bonus when it belongs to a cloud server, where one machine can create hundreds of accounts.

  • Hold rewards for review

    Hold a reward when the offer click or the claim came from a hosting range, because advertisers often reject or reverse those conversions.

  • Audit your traffic

    Run the addresses from yesterday's sign-up or click log through the lists to see how many came from servers, Tor exits or Private Relay.

Check an address

The lookup runs in your browser with the same matcher the Node.js package uses. Nothing you type leaves this page.

IPv4, IPv6, IPv4-mapped IPv6 (::ffff:1.2.3.4) and bracketed forms are accepted.

What the lists do not cover. Residential proxies and most commercial VPNs are not listed: they route traffic through home and mobile connections or through hosts without a public feed. Treat a match as one signal next to device and behavior checks, not as a verdict.

How do I check my own IP?

This page makes no network requests of its own, so it cannot see your address. Find your public IP one of these ways, then paste it above:

  • Search for "what is my IP" in your search engine.
  • Open your router's admin page. The status screen shows the WAN or internet address.
  • In a terminal, curl https://checkip.amazonaws.com prints your IPv4 address.

An address that starts with 10., 172.16. to 172.31. or 192.168. is a private LAN address and is never listed.

Bulk check

Paste the addresses from a sign-up or click log, up to 500 at a time. They are checked in this tab with the same matcher and are never uploaded.

Spaces, commas and semicolons also separate addresses.

    Use it in your project

    The same lists and matcher for Node.js and PHP, or the plain text file for anything else. No dependencies.

    Node.js 22 or newer. Install from GitHub:

    Terminal
    npm install github:moonetix/datacenter-ip-ranges
    check.js
    const { isDatacenterIp, lookup } = require('datacenter-ip-ranges');

console.log(isDatacenterIp('3.5.140.1'));
console.log(isDatacenterIp('192.168.1.10'));
console.log(lookup('185.220.101.1'));

    Loading

    isDatacenterIp() covers the cloud, CDN and provider-service lists. lookup() checks every list, Tor exits and iCloud Private Relay included. From the command line: node bin/check.js 3.5.140.1.

    PHP 8.1 or newer, one file, standard extensions only. Clone the repo next to your code:

    Terminal
    git clone --depth 1 https://github.com/moonetix/datacenter-ip-ranges
    PHP
    require __DIR__ . '/datacenter-ip-ranges/php/DatacenterIp.php';

$ip = $_SERVER['REMOTE_ADDR'];
$fromServer = is_datacenter_ip($ip);

$torOrRelay = DatacenterIp::fromDataDir(null, ['tor', 'privacy-relay']);
$sharedExit = $torOrRelay->contains($ip);

    $fromServer is true for cloud, CDN and provider-service ranges. $sharedExit is true for Tor exits and iCloud Private Relay. Behind a proxy or CDN, read the visitor's address from the header your proxy sets, not REMOTE_ADDR.

    Plain text, one CIDR per line, for nginx, a firewall or any other language. The file changes only when a provider changes its ranges, so download it once a day, not on every request.

    Terminal
    curl -fsSL -o all.txt https://raw.githubusercontent.com/moonetix/datacenter-ip-ranges/main/data/all.txt
    Raw list URL
    https://raw.githubusercontent.com/moonetix/datacenter-ip-ranges/main/data/all.txt

    Tor exits and iCloud Private Relay are separate files: data/categories/tor.txt and data/categories/privacy-relay.txt. The README has the nginx geo setup.
